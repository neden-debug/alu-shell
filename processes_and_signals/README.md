# Processes and signals

| File | Description |
|---|---|
| `0-what-is-my-pid` | Displays its own PID |
| `1-list_your_processes` | Lists all processes in user format with hierarchy |
| `2-show_your_bash_pid` | Shows process lines containing `bash` |
| `3-show_your_bash_pid_made_easy` | PID and name of bash processes (no `ps`) |
| `4-to_infinity_and_beyond` | Prints "To infinity and beyond" forever |
| `5-dont_stop_me_now` | Stops `4-to_infinity_and_beyond` with `kill` |
| `6-stop_me_if_you_can` | Stops it without `kill`/`killall` |
| `7-highlander` | Says "I am invincible!!!" on SIGTERM |
| `67-stop_me_if_you_can` | Stops `7-highlander` |
| `8-beheaded_process` | Kills `7-highlander` with SIGKILL |
| `10-process_and_pid_file` | PID file + signal traps |
| `11-manage_my_process`, `manage_my_process` | start / stop / restart init script |
